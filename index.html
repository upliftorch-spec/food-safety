認識食品安全認證

GHP 餐飲衛生管理分級

依據《食品良好衛生規範準則》（GHP），衛福部食藥署推動餐飲衛生管理分級評核制度，由各縣市衛生局組成評核小組，針對餐廳的作業場所、設施及品保制度進行評核，分為「優」與「良」兩個等級。通過評核的業者代表其衛生管理達到一定水準。

HACCP 食品安全管制系統

HACCP（Hazard Analysis and Critical Control Points）是國際食品法典委員會（Codex Alimentarius）認可的食品安全管理系統，透過危害分析與重要管制點的系統化管理，從原料、加工、儲存到販售的每個環節進行風險控管。依據我國《食品安全管制系統準則》，通過 HACCP 衛生評鑑的業者，代表其食品安全管理已達到國際標準。

如何選擇安心餐廳？

選擇通過衛生評鑑的餐廳是保障食安的第一步。您可以透過本平台地圖查詢附近的認證餐廳，也可注意餐廳是否張貼衛生評鑑標章。此外，觀察餐廳環境整潔度、食材新鮮度與工作人員衛生習慣，也是判斷餐廳安全性的重要指標。

常見問題

什麼是餐飲衛生管理分級評核？

自民國 99 年起，衛福部推動餐飲衛生管理分級評核制度，由地方衛生局派員與專家組成評核小組，依據GHP 準則對餐飲業者的環境衛生、設備管理、從業人員衛生及品保制度等項目進行實地評核。評核結果分為「優」及「良」兩個等級，通過者可張貼分級標章供消費者辨識。

HACCP 認證與 GHP 評核有什麼差異？

GHP 是基礎的衛生管理規範，著重於環境清潔、人員衛生等基本條件；HACCP 則是進階的食品安全管理系統，需要建立完整的危害分析、管制點監控與矯正措施。HACCP 的要求更嚴格、涵蓋範圍更廣，適用於團膳、食品工廠等大規模供膳場所。目前依《食品安全管制系統準則》，一定規模以上的餐飲業者須強制實施 HACCP。

本平台的資料多久更新一次？

本平台的資料來自衛福部食藥署開放資料平台，後端每 60 分鐘向食藥署 API 取得最新資料。優良餐飲業者名單隨各縣市衛生局評核進度不定期更新，HACCP 認證資料則隨認證審核結果更新。請注意，部分歷史資料的認證狀態可能已變更，實際情況以各縣市衛生局公告為準。

為什麼有些餐廳在地圖上看不到？

由於本平台使用地址進行地理定位（geocoding），部分地址格式不完整或已變更的業者可能無法正確顯示在地圖上。此外，本平台僅收錄通過衛生評鑑或 HACCP 認證的業者，並非所有合法經營的餐廳都會出現。未出現在平台上不代表該餐廳不安全。
